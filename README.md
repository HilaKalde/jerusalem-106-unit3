# יחידה 3 – תדר 106: מתחברים ומאזינים

לומדת HTML לאונבורדינג נציגי המוקד העירוני 106 – עיריית ירושלים.
פתחו את `index.html` בדפדפן (במה 1200x675, RTL).

- `index.html` – כל השקפים, העיצוב והניווט (מבנה מוכן להמרה ל-Storyline – ראו ההערה בראש הקובץ).
- `assets/` – רקעים, לוגואים, אייקונים, סרטונים וצלילים.
